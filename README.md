# E-Commerce Shopping System in C++

A simple **console-based E-Commerce Shopping System** developed in **C++** for Programming Fundamentals / beginner university project.

This project simulates an online shopping platform where users can:

- Login with email and password  
- Select multiple products  
- Enter product quantity  
- Generate total bill  
- Choose payment method  
- Verify payment PIN  
- View order summary  
- Restart for new orders  

---

## Features

### User Login System
- Email verification  
- Password checking  
- Retry option for wrong credentials  

### Product Selection
Available products:

- Chair = Rs.2000  
- Table = Rs.5000  
- Laptop = Rs.15000  
- Mobile = Rs.30000  
- Cloths = Rs.1000  

### Quantity Validation
- Only positive quantity accepted  

### Billing System
- Auto calculates product bill  
- Multiple products supported  
- Final total bill displayed  

### Payment Methods
- JazzCash  
- EasyPaisa  
- Bank  

### PIN Security
- 3 attempts only  
- Wrong attempts block account  

### Order Summary
Displays:

- Email  
- Purchased Products  
- Total Quantity  
- Total Bill  
- Payment Method  
- Order Status
